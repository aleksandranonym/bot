# SingleCore

SingleCore — это минималистичное меню для GTA 5 RP, разработанное как безопасный standalone UI-проект на C# и ImGui.NET. Проект не вмешивается в сетевую игру, не читает память и не даёт нечестных преимуществ другим игрокам.

## Что входит в проект

- Минималистичный тёмный интерфейс
- 4 вкладки: Main, Visuals, Settings, Config
- переключение вкладок и горячая клавиша открытия меню
- настройка цвета, прозрачности и масштаба интерфейса
- сохранение настроек между запусками
- логи ошибок и система уведомлений
- чистая модульная архитектура

## Требования

- .NET 8 SDK
- Windows 10/11 (для запуска UI через OpenGL/SDL)

## Установка

1. Установите .NET 8 SDK.
2. Клонируйте репозиторий.
3. Откройте терминал в корне проекта.
4. Выполните:

```bash
dotnet restore
```

## Важное предупреждение

Этот проект реализует только графический интерфейс и логику внешнего меню. Он не содержит компонентов для чтения памяти, обхода античита, модификации сетевого трафика, вмешательства в игровую сессию или получения нечестного преимущества.
